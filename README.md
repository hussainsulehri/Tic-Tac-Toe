# Tic-Tac-Toe Game 🎮

Hey! 👋 Thanks for checking out my project.

This is a simple Tic-Tac-Toe game I built using HTML, CSS, and JavaScript. I wanted to practice my frontend skills, especially working with CSS Grid and DOM manipulation.

## How it works
It's the classic game we all know - you play as X or O against a friend on the same screen. 
- **X** goes first (Black color).
- **O** goes second (Blue color).
- First one to get 3 in a row wins!

## How to play
You don't need to install anything fancy. Just download the files and open `game.html` in your browser (Chrome, Firefox, whatever you use).

## Features
- Clean, minimal design.
- Shows a message when someone wins or if it's a draw.
- "New Game" and "Reset" buttons so you can play as many rounds as you want.

Feel free to look at the code if you're learning too. It's pretty straightforward.

Enjoy the game! 🚀
